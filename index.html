TBC Arena – Lagplanlegger

Klikk en class for å sette hvem som spiller hva. ✚ = registrert healer, ⚔ = dps, ✚⚔ = kan begge (hybrid). Rolle og 70-status settes per char i «Rediger roster»; tak per class og dispeller-krav under «Gyldige lag». For ✚⚔-chars velger du Healer/DPS på kortet — velger du ingenting, prøver forslagene begge.
